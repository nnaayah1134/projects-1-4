Quick Tips

On mobile, users usually need the search tool first.

This design keeps the form visible right away and moves extra explanation lower on the page.

That makes it easier for users to act quickly without reading everything first.

How This Tool Helps

Users start by typing an interest such as hiking, volunteering, coding, or fitness.

The user enters a city or ZIP code so the site can focus on nearby groups and organizations.

The tool would return local groups that match the user’s goals, helping them connect more easily.
